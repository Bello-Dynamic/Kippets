## How to Submit a Contribution

1. Fork the repository.
2. Create a new branch for your block or template change.
3. Commit your changes with clear, descriptive commit messages.
4. Submit a Pull Request (PR) explaining your changes.

*Please note: Ensure your submissions do not include any proprietary code from your own private projects.*
